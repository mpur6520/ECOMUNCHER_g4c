# ECOMUNCHER

**ECOMUNCHER** is an environmental game created for the Games for Change (G4C) Student Challenge. The game combines basic gameplay with a message to encourage players to think about waste and keeping the environment clean.

## About the Game

Play as a slime that eats trash to clean up the environment in a set time frame. As you consume trash, you grow bigger and stronger.

## Controls

- **WASD** — Move
- **Z** — Eat
- **R** — Reset the game

## Play Online

[Play ECOMUNCHER](https://mpur6520.github.io/g4c/)

You may need to click the Run button more than once and click inside the game frame to begin playing.

## What I Learned

This project gave me experience creating a game around a specific theme and translating an environmental message into an interactive experience. It also provided an opportunity to work on gameplay mechanics and consider how a game can communicate an idea while remaining engaging for players.

## Project Context

Created for the Games for Change Student Challenge, which encourages students to use games to explore real-world issues.
